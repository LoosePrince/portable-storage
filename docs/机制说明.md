# 机制说明

## 木桶升级使用说明

### 绑定机制

**首次绑定**
1. 玩家A将普通木桶放入升级槽位
2. 木桶自动绑定到玩家A，成为"绑定木桶"
3. 玩家A可以将绑定木桶从升级槽位取出作为方块放置到世界中

**绑定转移**
1. 玩家A将绑定木桶从升级槽位取出
2. 绑定木桶作为物品丢出或交易给其他玩家
3. 玩家B拾取这个绑定木桶并放入自己的升级槽位
4. 现在玩家B的仓库与玩家A的仓库共享（合并显示）

### 仓库共享机制

**共享显示**
- 当玩家B使用玩家A的绑定木桶时，玩家的仓库界面会显示合并后的物品列表
- 物品的提取和存入遵循优先级：优先操作自己的仓库
- 支持多玩家同时共享同一仓库组

**多玩家共享**
- 玩家A的绑定木桶可以被多个玩家同时使用
- 所有使用该绑定木桶的玩家都共享同一个仓库视图
- 系统会自动处理物品的同步和一致性

### 自动化设备交互

**绑定木桶方块**
1. 将绑定木桶作为方块放置到世界中
2. 右键打开放入标记物品以启用交互，白名单制
3. 自动化设备（如漏斗）可以：
   - 从绑定木桶中提取仓库内存在的物品
   - 向绑定木桶输入物品到共享仓库
   - 绑定木桶内的标记物品不会被自动化设备取出

## 拼音搜索机制

### 搜索匹配流程

1. **直接文本匹配**：优先进行直接的中文文本匹配
2. **拼音转换匹配**：如果直接匹配失败，则进行拼音转换匹配
3. **多音字处理**：自动识别多音字并尝试所有可能的读音
4. **大小写不敏感**：支持大小写混合输入

## 收藏与静态模式

### 收藏机制

- 在仓库物品条目上点击中键可切换收藏状态。
- 收藏状态会独立保存，并随仓库数据同步，不依赖当前列表是否重新构建。
- 收藏物品稳定排在其它物品前面，优先级高于当前排序模式。
- 普通物品、流体储量和瓶装经验都可以继承收藏状态并参与收藏排序。

### 静态模式

- 按住 `Ctrl` 时进入静态模式。
- 静态模式下，存取操作只更新数量，不重排当前列表。
- 数量变为 0 的条目会暂时保留在原位置并显示 0。
- 松开 `Ctrl` 或关闭界面后恢复正常排序和显示。

## 工具升级与快捷工具调用

### 工具升级

1. 将任意斧、镐、锄、锹放入工具升级槽。
2. 右键工具升级槽打开 3x3 工具容器。
3. 工具容器中的物品存放在仓库的统一存储中，会占用仓库种类上限。
4. 工具容器条目与普通仓库条目隔离：同种物品不会互相合并，也不会出现在主仓库列表、搜索结果和普通排序结果中。
5. 放入工具容器的物品必须满足仓库存储条件，包括容量规则和 NBT 大小限制。

### 快捷工具调用

1. 在按键设置中绑定“快捷工具调用”，默认未绑定。
2. 按住快捷键进入选择状态，HUD 会显示一个无背景取消格和 9 个工具槽。
3. 默认选中最左侧取消格；按 `0` 或滚轮可选择取消格，松开按键不会交换或存取。
4. 按 `1-9` 选择对应工具槽，也可以用鼠标滚轮循环选择。
5. 松开快捷键后，客户端只发送选择结果，实际换手由服务端执行。
6. 选中有物品的工具槽时，工具槽物品进入主手，主手原物品进入该工具槽。
7. 选中空工具槽时，如果主手有物品，会尝试把主手物品存入该工具槽；如果不满足仓库存储条件，则不会执行。

## 快捷折叠与自动折叠

### 快捷展开/折叠

- 可在按键设置中绑定“展开/折叠仓库”，默认未绑定。
- 在背包、工具容器、绑定木桶以及支持仓库 UI 的容器界面中可触发。
- 该快捷键复用仓库原有折叠状态，不新增按钮，也不改变原按钮行为。

### 关闭界面自动折叠

- 可在客户端设置中开启“关闭界面时自动折叠仓库”，默认关闭。
- 开启后，关闭背包或容器界面时会自动将仓库设为折叠。
- 界面内部刷新、重建、手动展开不会立即触发自动折叠。
